Tutorials
=========

Step-by-step guides that walk through complete library design workflows.
Each tutorial builds a realistic library from scratch, explaining design
decisions along the way.

- :doc:`dms_gb1` — build a deep mutational scanning library for protein
  GB1, combining single and pairwise amino acid substitutions, random
  higher-order mutants, and wild-type replicates.
- :doc:`mpra_regulatory_grammar` — design an MPRA library that places
  three transcription factor binding sites at random positions within a
  regulatory element and pairs each variant with a unique barcode.
