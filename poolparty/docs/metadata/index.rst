Sequence Metadata
=================

It is often useful to record how each sequence within a library was
constructed. PoolParty provides three complementary ways to do this:

- :doc:`design_cards` — structured records of every design choice
  (mutation positions, scores, orientations) as DataFrame columns.
- :doc:`naming` — dot-separated names that summarize each sequence's
  construction history at a glance.
- :doc:`styling` — per-character colour annotations that visually
  highlight mutations, regions, and other features.
